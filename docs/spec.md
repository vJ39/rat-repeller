# rat-repeller 設計書

## 目的
ネズミ撃退を狙い、高周波音を鳴らし続けるCUIアプリ。ON/OFF切替と周波数調整をターミナル画面上で行う。

## 技術的制約(重要)
- 市販のネズミ撃退器は概ね20kHz〜65kHzの超音波を使う。
- 一般的なPC内蔵スピーカーは再生可能な上限が20kHz前後で、実機では16〜18kHzあたりから出力が急減衰する製品が多い。内蔵スピーカーのままでは「本物の超音波」を十分な音圧で出せない可能性が高い。効果を狙うなら高域再生に対応した外部スピーカー/ツイーターが必要になる。
- 18〜20kHz付近は可聴域に含まれる人がおり(特に若年層)、聞こえた場合は不快感を伴う。ペット(犬・猫)にはより高い周波数まで聞こえる。
- 上記の理由から、周波数はターミナル上で自由に調整できるようにし、環境に応じて可聴域外に追い込めるようにする。

## アーキテクチャ
- `src/lib.rs`: オーディオロジックのコア。GUI/ハードウェアに依存しないためテスト可能。
  - `Waveform`: `Sine` / `Square` / `Sawtooth` / `Triangle` の4種類。位相`phase`(0.0〜1.0)を受け取り`[-1.0, 1.0]`のサンプル値を返す。
    - Sine: `sin(2π·phase)`
    - Square: `phase < 0.5` なら `1.0`、それ以外は `-1.0`
    - Sawtooth: `2.0·phase - 1.0`
    - Triangle: `1.0 - 4.0·|phase - 0.5|`
  - `WaveformGenerator`: サンプルレート・中心周波数・位相・on/off状態・波形種別・スイープ状態(有効/無効・変調幅・変調速度・LFO位相・LFO上昇比率)を保持し、`next_sample()`でサンプル値を1つ生成する。デフォルト波形は`Sine`。
  - スイープ無効時は中心周波数の固定波形。有効時は実効周波数を`中心周波数 + 変調幅 * lfo(LFO位相)`として時間変化させ、慣れを防ぐ。
  - LFO波形は非対称三角波。上昇比率`rise_ratio`(0.0〜1.0、デフォルト0.5=対称)で「上げは長め・下げは短め」のような非対称な揺れ方を作れる。位相`p`に対し、`p < rise_ratio`の区間で`-1→+1`に線形上昇、`p >= rise_ratio`の区間で`+1→-1`に線形下降する。`rise_ratio`は0除算を避けるため`[0.01, 0.99]`にクランプする。
  - 実効周波数はサンプルレートのナイキスト周波数未満にクランプする。
- `src/main.rs`: TUIとオーディオ出力の配線。
  - TUI: `ratatui` + `crossterm`。画面には現在のON/OFF状態・波形種別・スイープ状態・中心周波数・瞬時周波数・瞬時周波数の推移グラフ(`Sparkline`)・操作ヘルプを表示する。
    - スペースキー: ON/OFF切替
    - `s`キー: スイープモード切替
    - `w`キー: 波形切替(Sine→Square→Sawtooth→Triangle→Sineと循環)
    - ↑/↓キー: 周波数を10Hz単位で増減
    - Shift+↑/↓キー: 周波数を1000Hz単位で増減
    - ←/→キー: スイープ速度(変調周波数)を0.05Hz単位で増減(下限0.05Hz、上限100Hz、初期値0.3Hz)。Shift+←/→は1Hz単位の粗い調整
    - `[`/`]`キー: スイープ範囲(周波数偏移)を10Hz単位で増減(下限100Hz、上限5000Hz、初期値1000Hz)
    - `a`/`d`キー: スイープの上昇比率を5%単位で増減(下限5%、上限95%、初期値50%=対称)
    - 周波数の下限20Hz、上限は出力デバイスのナイキスト周波数未満(可聴域〜超音波域まで通しで試せるようにするため)
    - qキー: 終了
  - 起動画面: `src/pixel_canvas.rs`の`PixelCanvas`(vJ39の他リポジトリ`termmap`/`misterdrillerterm`と同じ手法)でロゴ画像(`docs/logo.png`)をスプラッシュ表示する。論理ピクセルを縦2つ1組にし、上半分ブロック文字`▀`(fg=上ピクセル色, bg=下ピクセル色)で1端末セルにまとめることで疑似2倍解像度のピクセルアートにする。通常のANSI truecolor出力のみで完結するため、Sixel/Kitty/iTerm2等の画像プロトコル対応状況に依存しない。起動直後に表示し、何らかのキー入力で閉じてメイン画面に遷移する。
  - オーディオ出力: `cpal`のデフォルト出力デバイスのうち、F32出力に対応する設定から最大サンプルレートのものを選んでストリームを張る(サンプルレートが高いほど出せる周波数の上限が上がるため)。コールバック内で`WaveformGenerator::next_sample()`を呼び出し、その回の実効周波数(瞬時周波数)を共有状態に書き戻す。
  - TUIの入力ループ(メインスレッド)とオーディオコールバック(cpalの別スレッド)の間は`Arc<AtomicBool>`(on/off・スイープ有効)・`Arc<AtomicU32>`(中心周波数Hz・スイープ範囲Hz・スイープ速度ミリHz・瞬時周波数ミリHz・波形種別)で共有し、ロックを取らない。
  - 瞬時周波数の推移は固定長(200サンプル)のリングバッファとしてUIループ側で保持し、`Sparkline`でスクロール表示する。更新間隔はキー入力頻度に依存させず、実時間ベース(100ms間隔)で行う。OFF中は履歴を進めず、直前までの推移をそのまま保持する。
  - 操作ヘルプは項目単位のリストとして持ち、画面幅から概算した表示幅(ASCII=1、非ASCII=2)に収まるよう`wrap_items`で複数行に折り返す。1項目が画面幅を超える場合でも項目の途中では折り返さない。ヘルプ表示欄の高さは折り返し後の行数に応じて動的に決める。
- `src/persistence.rs`: 起動時の全設定(on/off・周波数・波形・スイープ有効/範囲/速度/上昇比率)と瞬時周波数の推移グラフを終了時に保存し、次回起動時に復元する。
  - 保存先は`dirs::config_dir()`配下の`rat-repeller/state.json`(`serde_json`でシリアライズ)。
  - 保存/読み込み関数はパスを引数で受け取る形にし、実ファイルシステムに依存しないテストを可能にする。
  - 保存ファイルが存在しない、壊れている、旧バージョンで形式が変わっている等の場合は読み込みを諦めてデフォルト値で起動する(エラーにしない)。
  - 保存タイミングは`q`/`Ctrl-C`による通常終了時のみ。

## テスト方針(テストファースト)
`src/lib.rs`のコアロジックに対しユニットテストを先に書く。
- off状態では常に`0.0`を返す。
- on状態では振幅が`[-1.0, 1.0]`に収まる。
- 指定周波数どおりの周期でゼロクロスすること(サンプルレート/周波数から期待ゼロクロス位置を計算し検証)。
- 周波数が0以下、またはナイキスト周波数以上の場合はクランプされること。
- 実行中に周波数を変更した場合、次のサンプルから新周波数が反映されること。
- スイープ無効時は固定周波数と同じ波形になること(後方互換性)。
- スイープ有効時も振幅が`[-1.0, 1.0]`に収まること。
- スイープ有効時、実効周波数がナイキスト周波数未満にクランプされ続けること。
- 変調幅・変調速度に負値を渡すと0にクランプされること。
- デフォルト波形は`Sine`であること(後方互換性)。
- 各波形(`Square`/`Sawtooth`/`Triangle`)が位相の特徴点(0, 0.25, 0.5, 0.75)で理論値どおりの値を返すこと。
- 波形を切り替えられ、振幅が常に`[-1.0, 1.0]`に収まること。
- デフォルトのLFO上昇比率は0.5であること。
- 上昇比率0.5のLFOは対称三角波(`Waveform::Triangle`)と同じ値になること。
- 上昇比率を変えると、ピーク(+1)に達する位相の位置がその比率どおりに動くこと。
- 上昇比率に0や1を渡しても0除算せず、`[0.01, 0.99]`にクランプされること。

`src/pixel_canvas.rs`の`PixelCanvas`は`misterdrillerterm`と同じテスト観点を移植する。
- 生成直後は指定した背景色で埋まっていること。
- 範囲外座標への`set`は無視され、パニックしないこと。
- 高さが偶数/奇数どちらでも`to_lines`が正しい行数を返すこと。
- `scale`で拡大・縮小した場合、出力サイズがそれに応じて変わること。
- 極端に小さい`scale`を渡しても出力が空にならないこと。

`src/main.rs`の`wrap_items`/`display_width`(ヘルプ折り返し)も純粋関数としてテストする。
- ASCII文字は幅1、非ASCII文字は幅2として計算されること。
- 全項目が収まる幅なら1行にまとまること。
- 収まらない場合は複数行に折り返され、1項目の途中では分割されないこと。
- 項目が空でもパニックしないこと。

`src/persistence.rs`もテストファーストで実装する。
- 保存直後に同じパスから読み込むと、保存した値と一致すること。
- ファイルが存在しないパスから読み込むと`None`を返すこと(エラーにしない)。
- 壊れたJSON(不正な内容)を読み込んでも`None`を返すこと(パニックしない)。
- 保存先ディレクトリが存在しない場合は作成してから書き込むこと。

TUI/スプラッシュ描画部分(ratatui)は手動起動確認のみとし、自動テスト対象はコアロジックとピクセル変換ロジックに限定する。
