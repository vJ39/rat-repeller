# rat-repeller 設計書

## 目的
ネズミ撃退を狙い、高周波音を鳴らし続けるCUIアプリ。ON/OFF切替と周波数調整をターミナル画面上で行う。

## 技術的制約(重要)
- 市販のネズミ撃退器は概ね20kHz〜65kHzの超音波を使う。
- 一般的なPC内蔵スピーカーは再生可能な上限が20kHz前後で、実機では16〜18kHzあたりから出力が急減衰する製品が多い。内蔵スピーカーのままでは「本物の超音波」を十分な音圧で出せない可能性が高い。効果を狙うなら高域再生に対応した外部スピーカー/ツイーターが必要になる。
- 18〜20kHz付近は可聴域に含まれる人がおり(特に若年層)、聞こえた場合は不快感を伴う。ペット(犬・猫)にはより高い周波数まで聞こえる。
- 上記の理由から、周波数はターミナル上で自由に調整できるようにし、環境に応じて可聴域外に追い込めるようにする。

## アーキテクチャ
- `src/lib.rs`: オーディオロジックのコア。GUI/ハードウェアに依存しないためテスト可能。
  - `Waveform`: `Sine` / `Square` / `Sawtooth` / `Triangle` の4種類。位相`phase`(0.0〜1.0)を受け取り`[-1.0, 1.0]`のサンプル値を返す。
    - Sine: `sin(2π·phase)`
    - Square: `phase < 0.5` なら `1.0`、それ以外は `-1.0`
    - Sawtooth: `2.0·phase - 1.0`
    - Triangle: `1.0 - 4.0·|phase - 0.5|`
  - `WaveformGenerator`: サンプルレート・中心周波数・位相・on/off状態・波形種別・スイープ状態(有効/無効・変調幅・変調速度・LFO位相)を保持し、`next_sample()`でサンプル値を1つ生成する。デフォルト波形は`Sine`。
  - スイープ無効時は中心周波数の固定波形。有効時は実効周波数を`中心周波数 + 変調幅 * sin(LFO位相)`として時間変化させ、慣れを防ぐ。
  - 実効周波数はサンプルレートのナイキスト周波数未満にクランプする。
- `src/main.rs`: TUIとオーディオ出力の配線。
  - TUI: `ratatui` + `crossterm`。画面には現在のON/OFF状態・波形種別・スイープ状態・中心周波数・瞬時周波数・瞬時周波数の推移グラフ(`Sparkline`)・操作ヘルプを表示する。
    - スペースキー: ON/OFF切替
    - `s`キー: スイープモード切替
    - `w`キー: 波形切替(Sine→Square→Sawtooth→Triangle→Sineと循環)
    - ↑/↓キー: 周波数を10Hz単位で増減
    - Shift+↑/↓キー: 周波数を1000Hz単位で増減
    - ←/→キー: スイープ速度(変調周波数)を0.05Hz単位で増減(下限0.05Hz、上限3.0Hz、初期値0.3Hz)
    - PageUp/PageDownキー: スイープ範囲(周波数偏移)を100Hz単位で増減(下限100Hz、上限5000Hz、初期値1000Hz)
    - 周波数の下限20Hz、上限は出力デバイスのナイキスト周波数未満(可聴域〜超音波域まで通しで試せるようにするため)
    - qキー: 終了
  - 起動画面: 対応端末(Sixel/Kitty/iTerm2画像プロトコル)ではロゴ画像(`docs/logo.png`)を`ratatui-image`で表示する。`Picker::from_query_stdio()`が失敗する(非対応端末等)場合はテキストタイトルにフォールバックする。
  - オーディオ出力: `cpal`のデフォルト出力デバイスのうち、F32出力に対応する設定から最大サンプルレートのものを選んでストリームを張る(サンプルレートが高いほど出せる周波数の上限が上がるため)。コールバック内で`WaveformGenerator::next_sample()`を呼び出し、その回の実効周波数(瞬時周波数)を共有状態に書き戻す。
  - TUIの入力ループ(メインスレッド)とオーディオコールバック(cpalの別スレッド)の間は`Arc<AtomicBool>`(on/off・スイープ有効)・`Arc<AtomicU32>`(中心周波数Hz・スイープ範囲Hz・スイープ速度ミリHz・瞬時周波数ミリHz・波形種別)で共有し、ロックを取らない。
  - 瞬時周波数の推移は固定長(200サンプル)のリングバッファとしてUIループ側で保持し、`Sparkline`でスクロール表示する。更新間隔はキー入力頻度に依存させず、実時間ベース(100ms間隔)で行う。

## テスト方針(テストファースト)
`src/lib.rs`のコアロジックに対しユニットテストを先に書く。
- off状態では常に`0.0`を返す。
- on状態では振幅が`[-1.0, 1.0]`に収まる。
- 指定周波数どおりの周期でゼロクロスすること(サンプルレート/周波数から期待ゼロクロス位置を計算し検証)。
- 周波数が0以下、またはナイキスト周波数以上の場合はクランプされること。
- 実行中に周波数を変更した場合、次のサンプルから新周波数が反映されること。
- スイープ無効時は固定周波数と同じ波形になること(後方互換性)。
- スイープ有効時も振幅が`[-1.0, 1.0]`に収まること。
- スイープ有効時、実効周波数がナイキスト周波数未満にクランプされ続けること。
- 変調幅・変調速度に負値を渡すと0にクランプされること。
- デフォルト波形は`Sine`であること(後方互換性)。
- 各波形(`Square`/`Sawtooth`/`Triangle`)が位相の特徴点(0, 0.25, 0.5, 0.75)で理論値どおりの値を返すこと。
- 波形を切り替えられ、振幅が常に`[-1.0, 1.0]`に収まること。

TUI/画像表示部分(ratatui, ratatui-image)は手動起動確認のみとし、自動テスト対象はコアロジックに限定する。
